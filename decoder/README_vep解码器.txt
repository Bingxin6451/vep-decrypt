大黄蜂云课堂 .vep 视频解码器
================================

一、这是什么
--------------------------------
把「大黄蜂云课堂」加密的 .vep 课程视频，解码成普通 MP4 文件的工具。
解码后可用任意播放器（PotPlayer / MPC / 手机 / 电视）播放，无需账号授权。

二、原理（简单说）
--------------------------------
.vep 文件结构：
  [CRYP头16字节] + [加密区: ftyp/moov头/视频SPS] + [明文索引表] + [视频音频数据]
                    ^^^^^^^^^^^^^^^^^^^^^^^^               ^^^^^^^^^^^^^^^^
                    这部分含解码必需的 SPS                    主体为明文

工具做的事：
  1. 自动定位加密区边界与各轨道索引表
  2. 按标准 x264 High profile 参数「重建」SPS 解码头
  3. 从明文流里提取 PPS、视频、音频
  4. 用 ffmpeg 重新封装成标准 MP4

三、使用效果
--------------------------------
  · 分辨率 / 时长 / 音轨 完全正确
  · 画面完整、音视频同步
  · 实测 73 分钟 1080p 课程，解码耗时约 2 秒
  · 输出为标准 MP4（H.264 + AAC），兼容所有播放器与移动设备

四、使用方法
--------------------------------
方法 A（拖拽，最简单）：
  把 .vep 文件直接拖到 vep解码器.exe 上，
  自动在 .vep 同目录生成 "原文件名_解码.mp4"

方法 B（命令行）：
  vep解码器.exe "D:\课程\某某.vep"
  → 生成 "D:\课程\某某_解码.mp4"

方法 C（批量）：
  vep解码器.exe D:\课程\*.vep
  （Windows 下通配符批量需在命令行里跑，拖拽多个文件也可以）

五、打包成 exe（在 Windows 上）
--------------------------------
1. 安装 Python 3.8+（勾选 Add to PATH）
2. 准备四个文件放同一目录：
     decode_vep.py      解码器主程序
     build_exe.bat      打包脚本
     ffmpeg.exe         Windows 静态版（见下）
3. 双击 build_exe.bat，生成 dist\vep解码器.exe

ffmpeg.exe 下载：
  https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip
  解压后取 bin\ffmpeg.exe

六、适用格式
--------------------------------
· 本工具针对「快速加密」类 .vep（加密区 + 关键帧加密，主体明文）。
· 对「完整加密」类 .vep（整个文件加密）请使用对应的完整解密流程。
· 仅用于解码你自己购买、有合法授权的课程视频。

七、技术要点（供二次开发）
--------------------------------
· 文件头: 'CRYP' + u32le(加密区长度) + u32le(A) + u32le(B)
· A/B 为文件级校验字段，随文件变化，不可硬编码
· 加密区: data[16 : 16+加密区长度]，XOR 流构造
· 视频轨 stbl 的 stsz/stco/stsc/stss 在明文区，可按 mp4 atom 自动定位
· stco 内所有偏移需 +16（CRYP 头长度修正）
· SPS 重建参数：High profile, level 4.0, poc_lsb=6bit, maxref=4
· 帧率：从 视频帧数/音频时长 反推，写入 SPS VUI（num_units_in_tick=500）
· PPS 从明文流第一个 type-8 NAL 提取，每片源不同
